# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application where users can browse different types of houseplants and add their favorite plants to a shopping cart.

## Features

- Browse houseplants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease product quantities.
- Remove plants from the cart.
- View the total price of items in the cart.

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Redux
